
# 📊 Day 02 - Bar Plot

## 🎯 Objective

Learn how to create a basic Bar Plot using Matplotlib to visualize the average price of Toyota cars for each age.

---

## 📚 Topics Covered

- Reading a CSV file using Pandas
- Removing missing values using `dropna()`
- Grouping data using `groupby()`
- Calculating average values using `mean()`
- Sorting values using `sort_index()`
- Creating a Bar Plot using Matplotlib

---

## 🛠 Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📂 Dataset

Toyota.csv

---

## 💻 Python Code

**File:** `bar_plot.py`

### Steps Performed

1. Loaded the Toyota dataset.
2. Removed missing values.
3. Grouped the data by the `Age` column.
4. Calculated the average `Price` for each age.
5. Displayed the result using a bar chart.
6. Added a title and axis labels.

## 📖 Observation

The bar plot shows the average price corresponding to each car age. It allows easy comparison of average prices across different ages, although the large number of age values makes the chart more crowded than a line plot.
